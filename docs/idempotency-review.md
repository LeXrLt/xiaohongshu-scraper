## 使用方式

```bash
# 默认继续未完成笔记
python scripts/merchant.py extract
# 显式重抽一篇已完成笔记
python scripts/merchant.py extract --note-id <id> --force
# 默认继续列表进度
python scripts/xhs.py crawl-search "香港" --max-pages 2
# 显式重新从第一页发现新内容
python scripts/xhs.py crawl-search "香港" --restart --max-pages 2
# 仅预览确定性重复商户
python scripts/merchant.py dedupe
```

抓取列表完成后需要主动发现新发布内容时使用 `--restart`；单篇详情主动更新使用 `note --force`，定期轮询更新使用 `refresh`。关闭下载或分析选项时不执行对应待处理媒体任务。
